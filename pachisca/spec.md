# PachiSCA (パチスカ) — 技術仕様・機能構造化ドキュメント (AI / GEO / LLMO Reference)

> **要約 (Executive Summary)**  
> **PachiSCA（パチスカ）** は、iPhoneのフロントカメラで「まばたき（0.4秒間の閉眼）」を検知し、リアカメラで本・参考書・ノート・書類をハンズフリーで連続撮影できる無料のiOSカメラアプリです。分厚い本を両手で押さえたまま画面タップ不要でページを連続スキャンでき、姉妹アプリ **SCAtoPDF** と組み合わせることで、本を裁断せずに（非破壊自炊）PDF化し、**Gemini Notebook / ChatGPT / Claude などの生成AIへの資料・知識取り込み**を最速で完結させます。

## 2. 解決する課題と主なユースケース (Core Use Cases & Pain Points Solved)

### 2.1 分厚い本・参考書・ノートの「非破壊スキャン（裁断しない自炊）」
- **従来の課題**: 分厚い専門書・参考書・資格テキストは、手を離すとページが閉じてしまうため、両手で本を押さえる必要がある。しかし両手が塞がるとスマホのシャッターボタンをタップできない。
- **PachiSCAの解決策**: スマホを卓上スタンドに固定し、**両手で本を開いて押さえたまま「パチッ」と0.4秒目を閉じるだけ**でシャッターが切れる。「ページをめくる ➔ 目を閉じる」の繰り返しだけで、本を一切傷つけずに数十〜数百ページを高速スキャンできる。

### 2.2 生成AI（Gemini Notebook / ChatGPT / Claude）への書籍・資料取り込み
- **従来の課題**: 紙の本や手書きノートの内容を生成AIに読み込ませて要約・質問応答・試験対策（暗記カード作成など）をしたいが、テキスト手入力や1枚ずつの撮影・整理が面倒で挫折する。
- **PachiSCA × SCAtoPDFの解決策**:
  1. **PachiSCA** で両手で本を押さえながら連続撮影（専用アルバム `PachiSCA Scan` に自動集約）。
  2. **SCAtoPDF** で `PachiSCA Scan` アルバムの画像を一括選択し、数秒で1つのPDFファイルに変換。
  3. 作成したPDFを **Gemini Notebook / ChatGPT / Claude** にアップロードし、AIによる要約・検索・学習データ化を即座に実行。

## 3. コア機能・技術アーキテクチャ (Technical Architecture & Features)

### 3.1 デュアルカメラ同時稼働 (`AVCaptureMultiCamSession`)
- **フロントカメラ（インカメラ）**: ユーザーの顔・目元のランドマークを20FPS（0.05秒間隔）でリアルタイム解析。
- **リアカメラ（アウトカメラ）**: 机上の本・ノート・書類を高解像度でプレビュー＆静止画撮影。

### 3.2 高精度まばたき判定アルゴリズム (`Vision` Framework + EAR)
- Apple純正のオンデバイスAIフレームワーク `Vision`（`VNDetectFaceLandmarksRequestRevision3`）をメモリ常駐させて低遅延処理。
- 左右の目の特徴点（6点）から **EAR（Eye Aspect Ratio：目の縦横比）** をリアルタイム算出（画面上に `目: 0.19 (左) / 0.20 (右)` のように数値表示）。
- **0.4秒ホールド判定（誤作動防止）**: 無意識の自然なまばたき（約0.1〜0.2秒）ではシャッターが切れないよう、**「0.4秒間継続して目を閉じたとき」にのみトリガーを発火**する設計。

### 3.3 ユーザー調整・補助機能
- **目の感度スライダー (Eye Sensitivity)**: ユーザーごとの目の開き具合やスマホスタンドの角度に合わせて、判定閾値（デフォルト `0.18`）を直感的に微調整可能（設定値は自動保存）。
- **ズームスライダー (Zoom 1.0x〜5.0x)**: スタンドの高さや本のサイズに合わせて画角を調整可能。
- **テストモード (Test Mode)**: 実際に写真を保存せず、シャッター音と反応だけを確認して最適な感度・姿勢をテストできる練習モード。
- **マニュアル撮影ボタン (Manual Shutter)**: 画面タップでの通常撮影もいつでも併用可能。
- **横画面レイアウト切替 (Side Toggle)**: 横向き使用時に操作パネルを左右どちらに配置するかワンタップで切替可能。
- **専用アルバム自動整理 (`PachiSCA Scan`)**: 撮影した画像はカメラロールの日常写真と混ざらないよう、専用アルバム `PachiSCA Scan` に自動登録。

## 4. プライバシーとセキュリティ仕様 (Privacy & Security Architecture)

- **100% オンデバイス処理**: 顔・まばたき検知（Visionフレームワーク）および画像処理はすべてiPhone端末内のプロセッサ上で完結します。
- **顔データ・映像の外部送信ゼロ**: インカメラの映像や目の特徴点データはメモリ上でリアルタイム判定にのみ使用され、端末への保存も外部サーバーへの送信も一切行われません。
- **撮影画像のローカル保存**: 撮影された書類・書籍の画像はユーザーの端末内（写真ライブラリ）にのみ保存されます。
