# ClonzMaker — 技術仕様・機能構造化ドキュメント (AI / GEO / LLMO Reference)

> **要約 (Executive Summary)**  
> **ClonzMaker（クローンズメーカー）** は、iPhoneの写真ライブラリから1枚の写真を選ぶだけで、オンデバイスAI（Apple Vision）が人物・ペット・推しグッズなどの被写体を自動で背景切り抜きし、画面いっぱいに増殖・浮遊するユニークなショート動画（MP4/MOV）をワンタップ生成できる無料iOSアプリです。

## 2. コア機能・仕様 (Core Features & Specifications)

1. **AI自動被写体切り抜き（100% オンデバイス）**:
   - 写真を選ぶだけで、Apple純正のオンデバイスAIがメインの被写体（人物、犬・猫などのペット、料理、グッズ等）を瞬時に背景から切り抜きます。
2. **自由自在なクローン増殖カスタマイズ**:
   - **クローンの数**: 画面内を飛び交う被写体の数を調整可能。
   - **動きのスピード・基本サイズ・回転の傾向**: ゆったり浮遊する癒やし系動画から、高速回転するカオス動画まで自在に調整。
   - **動画の長さ・出現位置（センター / ランダム）・フェードイン / フェードアウト設定**。
3. **SNS（TikTok / Reels / Shorts / X）直結の書き出し**:
   - 生成した動画はワンタップでカメラロールへ保存・SNSへ直接シェア可能。
4. **完全ローカル処理でプライバシー安全**:
   - すべての画像切り抜きと動画レンダリングはiPhone端末内で完結し、写真が外部サーバーへアップロードされることは一切ありません。
